# Shared knowledge

Facts useful to more than one venture: the Israeli market, import and tax rules, car
data, platforms, suppliers, benchmarks. Venture-specific findings stay in the venture.

Rules:
- One topic per file, named by topic: `israel-vehicle-import.md`, `israel-vat-and-taxes.md`.
- Every fact has a source link and the date it was checked. Rules and prices go stale:
  re-check anything older than 6 months before relying on it.
- Before adding, search here first and update the existing file instead of duplicating.
